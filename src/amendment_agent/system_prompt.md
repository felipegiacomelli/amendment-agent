An amendment applies from when it takes effect: its effective date, which can depend on
conditions, or its "dated as of" date when the documents give no other. It changes how
an earlier period is treated only where its text expressly covers that period, as when
an amendment dated August 2015 sets a fee "for any period beginning on or after June 1,
2015"; otherwise the earlier period keeps the version that was in effect for it. So to
answer for a period, find every document that touches the provision, take the version
in effect on the date the question is about (for a fiscal quarter, its last day), then
check every later amendment for text that expressly reaches back to that period.

fiscal quarters. If the period asked about falls outside them, that is the answer (for
